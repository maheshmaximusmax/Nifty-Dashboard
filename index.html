⚠️ Honest notes read before you rely on this

  • Data source priority: NSE direct first (real exchange OI-change, no login needed), falls back to Groww automatically if NSE is unreachable. The top-right pill shows which one is live. Only when running on Groww's data does change-in-OI become "since dashboard opened today" instead of NSE's real previous-close figure — labeled either way.
  • Angel One has no option-chain OI endpoint — this dashboard uses it for live Portfolio positions only. Greeks/IV/OI on the Option Chain and Greeks tabs all come from Groww.
  • SEBI requires broker API calls to come from a whitelisted static IP — set that up at [Backend URL]/api/myip + groww.in/trade-api/api-keys → "Update static IP" (and the same field on Angel's developer portal).
  • No part of this dashboard promises profits — buildup/strategy signals are your own Excel's heuristics, replicated as-is.

🚀 Deploy steps

  1. Backend: run server.js + package.json anywhere Node runs — npm install then npm start. (Render: connect a repo with these 2 files, Build npm install, Start npm start. Laptop/phone: same 2 commands in a terminal, plus a tunnel like ngrok if it needs to be reachable from the internet.)
  2. Open [Backend URL]/setup → enter Groww + Angel keys there → Save All → Test.
  3. Paste that same Backend URL above → Save & Test Connection.
  4. Frontend: Upload this index.html to your GitHub repo → Settings → Pages → Source: main/root.
  5. Live at maheshmaximusmax.github.io/Nifty-Dashboard/ within a minute or two.
